# 公众号多 Agent 审稿流程 Prompt 手册

更新时间：2026-06-12
适用 Skills：`wechat-adversarial-review`、`wechat-reader-simulation`、`wechat-final-editor`
配套创作 Skill：`wechat-official-account-content`

这份手册用于把公众号文章从“AI 生成初稿”推进到“人工确认后发布”。核心目标是引入反对、挑错、读者模拟和终稿编辑机制，降低单一模型自嗨、迎合和漏风险的问题。

## 推荐总流程

```text
1. 使用 wechat-official-account-content 生成文章初稿
2. 使用 wechat-adversarial-review 做挑刺审稿
3. 使用 wechat-reader-simulation 做读者模拟
4. 使用 wechat-final-editor 合并修改并输出终稿
5. 人工确认事实、品牌、标题和发布时机后发布
```

## 1. 挑刺审稿：找硬伤

```text
使用 wechat-adversarial-review，对下面这篇公众号文章做挑刺审稿。

请重点检查：
1. 是否建议发布
2. 核心观点是否站得住
3. 标题和正文是否匹配
4. 事实、数据、案例、行业判断是否存在风险
5. 是否有 AI 自嗨、空泛正确、过度拔高
6. 是否有读者会反对或不信的地方
7. 是否有品牌错位或转化承接生硬

请输出：
1. 发布判断
2. 必改硬伤
3. 反对意见
4. 事实与风险清单
5. 建议删除或合并的部分
6. 最小修改路径

文章如下：
[粘贴文章]
```

## 2. 读者模拟：看读者体验

```text
使用 wechat-reader-simulation，模拟真实读者阅读下面这篇公众号文章。

请模拟这些读者：
1. 目标读者
2. 潜在客户
3. 忙碌读者
4. 挑剔同行
5. 沉默读者

请重点判断：
1. 标题和开头 10 秒内是否让人继续读
2. 哪些段落会让读者流失
3. 哪些表达会让读者反感或不信
4. 有没有转发、收藏、评论或咨询动机
5. 哪些地方需要为了读者体验优先修改

文章如下：
[粘贴文章]
```

## 3. 终稿编辑：合并修改

```text
使用 wechat-final-editor，根据原稿、挑刺审稿报告和读者模拟报告，输出可发布终稿。

要求：
1. 不要抛开原稿重写
2. 先处理发布阻断项和事实风险
3. 再处理读者流失点和反感点
4. 保留作者的核心判断和个人表达
5. 对不确定事实标注需人工确认
6. 输出可直接复制进公众号后台的终稿

原稿：
[粘贴原稿]

挑刺审稿报告：
[粘贴 wechat-adversarial-review 输出]

读者模拟报告：
[粘贴 wechat-reader-simulation 输出]

人工意见：
[填写你决定保留、删除或强调的内容；没有可写“暂无”]
```

## 快速版全链路 Prompt

```text
我现在要走公众号多 Agent 审稿流程。

第一步：使用 wechat-adversarial-review，先对文章做挑刺审稿，找硬伤、反对意见和事实风险。
第二步：使用 wechat-reader-simulation，模拟真实读者体验，找流失点、反感点、转发收藏和咨询动机。
第三步：等我把前两步结果发给你后，再使用 wechat-final-editor 合并修改，输出可发布终稿和人工确认清单。

文章如下：
[粘贴文章]
```

## 人工发布前确认

终稿输出后，人工至少确认四件事：

1. 事实、数据、案例、时间和来源是否可靠。
2. 标题是否真实兑现正文，不靠虚假悬念。
3. 是否符合账号和「未来弧线」品牌调性。
4. 文末互动、咨询和私域承接是否自然。
