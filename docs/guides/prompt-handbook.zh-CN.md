# 公众号创作技能包调用 Prompt 手册

更新时间：2026-07-31
适用 Skill：`wechat-official-account-content`
项目路径：`skills/wechat-official-account-content`

这份手册只保留 7 个主调用入口。以后不要再把一次公众号任务拆成很多层流程；先选一个主技能调用，再按需要追加一句增强要求。

## 使用原则

统一用这个开头：

```text
使用公众号创作技能包，也就是 wechat-official-account-content。
```

如果 agent 没有自动识别 skill，使用更明确的版本：

```text
请读取当前项目里的公众号创作技能包：
skills/wechat-official-account-content

然后按 SKILL.md 的 7 个主技能入口执行下面任务：
[填写任务]
```

最短内容链路：

```text
热门文章/10w+参考 → 标题生成 → 文案创作 → 封面图制作
```

竞品分析链路：

```text
黑马账号推荐 → 热门账号推荐 → 反哺选题和标题
```

旧入口合并方式：

```text
选题、热点、竞品文章 → 公众号热门文章查询
标题、开头、打开率 → 公众号标题生成
写文、改写、去 AI 味、质检、复盘、增长转化 → 公众号文案创作
封面字、封面设计 → 公众号封面图制作
对标账号、榜单、增长账号 → 黑马账号推荐 / 热门账号推荐
```

## 1. 公众号标题生成

适合：标题没想法、标题优化、爆款标题、提高打开率、基于关键词出标题。

```text
使用公众号创作技能包，调用「公众号标题生成」。

输入信息：
[粘贴关键词、选题、文章主题、草稿、原标题，或说明目标读者]

要求：
1. 如果能联网，先参考近期同赛道热门标题和趋势；不能联网时请说明未核实外部趋势
2. 生成 10-15 个公众号标题
3. 分为稳妥版、增长版、品牌版
4. 每个标题说明吸引点和风险
5. 推荐 1 个最适合发布的标题
6. 同步给 3 个封面字

如果是「未来弧线」内容，请标题面向商业/文旅甲方，强化巨型艺术装置、策展式商业和品牌空间价值，不要写成泛流量标题。
```

## 2. 公众号10w+文章

适合：研究爆文、找 10w+ 参考、看高传播文章特征、做每日爆文灵感。

```text
使用公众号创作技能包，调用「公众号10w+文章」。

领域/关键词：
[填写行业、关键词、账号类型、时间范围]

要求：
1. 如果能联网，查近期公开可验证的 10w+ 或高传播公众号文章
2. 标明来源、时间和可核实程度
3. 不确定真实阅读量时，不要写成确定 10w+，标为“疑似高传播案例”
4. 分析标题、选题、开头、结构、转发理由
5. 输出可借鉴和不能照搬的地方
6. 最后转译成适合我账号的选题或标题方向

如果用于「未来弧线」，请只保留能服务商业空间、巨型艺术装置、策展式商业、文旅甲方的启发。
```

## 3. 公众号热门文章查询

适合：按关键词主动搜索热门文章、追热点、找同赛道灵感、分析竞品文章。

```text
使用公众号创作技能包，调用「公众号热门文章查询」。

关键词/主题：
[填写关键词、热点、行业方向、竞品文章链接或标题列表]

要求：
1. 如果能联网，主动查询近期热门公众号文章或行业内容
2. 标明来源和时间
3. 判断这些内容为什么火
4. 提炼可写角度，而不是只列文章
5. 标出哪些方向适合直接写、哪些要重切角度、哪些只适合做素材、哪些不建议追
6. 输出一张可复制表格

如果是「未来弧线」选题，请快速检查：是否强化巨型艺术装置/策展式商业标签，是否体现专业壁垒，是否击中商业/文旅甲方痛点。
```

## 4. 公众号封面图制作

适合：公众号封面方向、封面字、2.35:1 横版封面、封面设计方案、图像生成 prompt。

```text
使用公众号创作技能包，调用「公众号封面图制作」。

文章主题/标题：
[填写主题、标题或粘贴文章]

参考风格/限制：
[可选：粘贴参考图、品牌色、禁用风格、图片素材说明]

要求：
1. 输出 2.35:1 横版公众号封面设计方案
2. 包含主视觉、封面字、构图、色彩、字体气质、素材需求
3. 给 3 个封面字备选
4. 给一段可直接用于图像生成的 prompt
5. 如果能联网，可参考同赛道爆款封面的视觉元素，但不要照搬

如果是「未来弧线」，封面必须突出空间现场、巨型艺术装置、策展式商业或艺术家创作气质，避免普通促销海报感。
```

## 5. 公众号文案创作

适合：写完整公众号文章、基于爆款数据写文、改写、品牌化、去 AI 味、AI 质检、发布前复盘、增长转化设计。

```text
使用公众号创作技能包，调用「公众号文案创作」。

任务类型：
[新写一篇 / 基于草稿改写 / 去 AI 味 / 品牌化改写 / AI 质检 + 发布前复盘]

输入信息：
[粘贴主题、关键词、素材、案例、草稿、爆文参考、目标读者、发布目的]

要求：
1. 默认给可直接发布版
2. 标准版控制在 1200-1800 字，避免短段落但全文过长
3. 先给标题、封面字、摘要，再给正文
4. 正文要有短段落、快节奏、案例穿插、观点推进
5. 去掉 AI 味：不要空泛正确、结构太工整、语气太端、金句太油、没有真实观察
6. 结尾给互动问题和低压力私域承接
7. 同步给小红书标题方向和视频号前 3 秒钩子

如果是「未来弧线」文章，请强制遵守：
1. 面向商业/文旅甲方，而不是泛设计爱好者
2. 主叙事顺序是：空间问题 → 装置创作判断 → 尺度/材料/工艺/场地拆解 → 商业结果
3. 强化“美院背景创意工作室、巨型艺术装置、策展式商业”的专业标签
4. 不把轻量美陈、展板、手绘、赛事氛围布置当成主案例
5. 案例没有实效数据时，不要硬推 ROI，要标明证据等级和数据缺口
6. 加入非共识判断、适用边界和反噬风险
```

草稿质检可直接这样调用：

```text
使用公众号创作技能包，调用「公众号文案创作」，对下面这篇文章做 AI 质检 + 发布前复盘。

请只输出：
1. 是否建议发布
2. 最大问题
3. 最该保留的部分
4. 必改问题表
5. 需要补充的数据、案例或装置细节
6. 可直接替换的标题、开头、关键段落和结尾 CTA

文章如下：
[粘贴文章]
```

## 6. 公众号黑马账号推荐

适合：找增长快的公众号、阅读增长率排行榜、研究哪些号在猛涨、寻找对标增长策略。

```text
使用公众号创作技能包，调用「公众号黑马账号推荐」。

领域/分类：
[填写行业、关键词、账号类型、时间范围]

要求：
1. 如果能联网，查近期增长快的公众号、阅读增长榜或第三方榜单
2. 标明来源、时间和增长依据
3. 无法验证增长率时，不要写具体排名
4. 分析增长原因：选题、标题、更新频率、账号定位、分发场景、内容形态
5. 输出可借鉴和不适合照搬的地方
6. 给我下周可以测试的 3 个动作

如果用于「未来弧线」，请优先找商业空间、文旅、艺术装置、设计、品牌营销、城市更新相关账号。
```

## 7. 公众号热门账号推荐

适合：找头部账号、综合实力榜、日榜/周榜/月榜、按分类了解头部玩家。

```text
使用公众号创作技能包，调用「公众号热门账号推荐」。

领域/分类：
[填写行业、关键词、日榜/周榜/月榜、账号类型]

要求：
1. 如果能联网，查公开榜单或可验证账号资料
2. 标明榜单口径、来源和时间
3. 区分热门账号和黑马账号：热门账号看长期影响力，黑马账号看增长变化
4. 输出账号定位、代表选题、标题风格、内容打法、商业化方式
5. 标注对标层级：直接对标、局部借鉴、只观察、不建议对标
6. 最后总结未来弧线可以学习什么
```

## 可选增强指令

这些不是新的技能入口，只是在 7 个主 prompt 后面追加的短要求。

### 未来弧线定位增强

```text
请把结果收回到「未来弧线」定位：美院背景创意工作室、巨型艺术装置、策展式商业、商业/文旅甲方、内容服务业务转化。
```

### 去 AI 味增强

```text
请按我的个人风格处理：清醒观察者 + 会聊天的朋友 + 犀利评论者。表达要直白有力、克制锋利、有观察笔记感和轻微吐槽感，不要固定句式清单。
```

### 专业可信度增强

```text
请检查案例证据等级：哪些有定量数据，哪些只是公开事实、一手观察、定性描述或推测。没有数据时不要把结论写成 ROI 证明。
```

### 一文多发增强

```text
请在公众号内容后补充小红书标题/正文方向、封面字、评论区引导，以及视频号标题、前 3 秒钩子、30-90 秒口播方向。
```

## 后续维护建议

- 新增能力时，优先判断能不能归入这 7 个主技能，不要轻易新增第 8 个入口。
- 如果某个 prompt 变长，先删冗余要求，再考虑拆分。
- 如果品牌定位变化，更新 `brand-future-arc.md`，再同步修改第 5 个主 prompt。
- 如果个人表达风格变化，更新 `personal-voice.md`，再同步修改“去 AI 味增强”。
