## 数据源可靠性分级

结论：这些来源可用，但不能一概当作强证据。后续在技能包中按以下分级使用。

| 等级 | 数据来源 | 可信度 | 适合用途 | 不适合用途 |
|---|---|---|---|---|
| A | 微信公众平台后台、自有账号数据、客户确认的数据截图、项目实际复盘数据 | 最高 | 判断真实阅读、打开、完读、转发、咨询、转化 | 无 |
| B | 微信官方公开信息、项目方/品牌方/场地方正式发布的数据 | 高 | 引用事实、项目结果、公开案例 | 推导未披露的 ROI |
| C | 新榜、西瓜数据等第三方新媒体数据平台 | 中高 | 找爆文线索、看趋势、看榜单、找对标账号、做选题参考 | 单独证明真实粉丝、真实阅读、精确增长率、转化率 |
| D | 媒体报道、行业文章、案例软文、公众号文章 | 中 | 找案例、找观点、辅助判断 | 当作经营实效或投入产出证明 |
| E | 社媒讨论、个人经验、未经核实截图 | 低 | 发现话题、找情绪和读者语言 | 写成确定事实 |

使用规则：

1. 选题、标题、竞品分析可以使用 C/D/E 级来源，但要标明“参考、趋势、线索”。
2. 文章中涉及“提升、带动、增长、转化、ROI”时，必须优先使用 A/B 级来源。
3. 只有 C 级第三方平台数据时，只能写“第三方平台显示/榜单显示/可作为观察”，不能写成绝对事实。
4. 没有 A/B 级数据时，未来弧线文章应把结论写成“创作启发、空间判断、可验证假设”，不要包装成实效证明。

## 7 个流程跑通记录

### 1. 公众号标题生成

测试输入：

```text
使用公众号创作技能包，调用「公众号标题生成」。
主题：商场为什么需要一个真正能被记住的巨型艺术装置？
如果是未来弧线内容，请面向商业/文旅甲方。
```

跑通结果：

- 能识别为标题入口。
- 会按需读取标题规则、未来弧线品牌规则、巨型装置定位规则。
- 输出结构明确：标题候选、推荐标题、封面字。
- 不会被旧的选题立项流程拖长。

结论：通过。

### 2. 公众号10w+文章

测试输入：

```text
使用公众号创作技能包，调用「公众号10w+文章」。
领域：商业空间、文旅、艺术装置。
请找高传播文章特征，并转译成未来弧线可写角度。
```

跑通结果：

- 能识别为爆文参考入口。
- 会先查公开来源；若无法确认真实 10w+，会降级为“疑似高传播案例”。
- 输出不只列文章，会提炼爆点、可借鉴、不能照搬和未来弧线转译角度。

结论：通过。限制是实时 10w+ 明细可能需要第三方平台权限。

### 3. 公众号热门文章查询

测试输入：

```text
使用公众号创作技能包，调用「公众号热门文章查询」。
关键词：策展式商业、巨型艺术装置、商业空间。
请判断哪些适合未来弧线写，哪些只是素材。
```

跑通结果：

- 能识别为主动搜索入口。
- 输出会按“直接写、重切角度、只做素材、放弃”分类。
- 能把热点收回到巨型艺术装置、策展式商业、商业/文旅甲方痛点。

结论：通过。

```text

标题：为什么商场需要一个真正能被记住的巨型装置？
请输出 2.35:1 横版封面设计方案和图像生成 prompt。
```

跑通结果：

- 输出规格明确：比例、主视觉、封面字、构图、色彩、字体、素材需求、生成 prompt。
- 未来弧线约束有效：避免普通促销海报，强调空间现场和巨型装置视觉识别。

结论：通过。

### 5. 公众号文案创作

测试输入：

```text
使用公众号创作技能包，调用「公众号文案创作」。
任务类型：新写一篇。
主题：商场为什么需要一个真正能被记住的巨型艺术装置？
请按未来弧线定位输出可直接发布版。
```

跑通结果：

- 能承接写文、改写、去 AI 味、质检、复盘、增长转化等正文类任务。
- 会默认控制标准版篇幅，避免文章过长。
- 未来弧线主叙事顺序清楚：空间问题 → 装置创作判断 → 尺度/材料/工艺/场地拆解 → 商业结果。
- 草稿质检也能在同一入口完成，不需要另起旧流程。

结论：通过。

### 6. 公众号黑马账号推荐

测试输入：

```text
使用公众号创作技能包，调用「公众号黑马账号推荐」。
领域：商业空间、文旅、艺术装置、设计、品牌营销。
请找增长快的对标账号，并给未来弧线下周可测试动作。
```

跑通结果：

- 能识别为增长对标入口。
- 会优先找成长榜、飙升榜、增长迹象。
- 无法验证增长率时不会编具体排名。
- 输出会落到可借鉴、不照搬、下周测试动作。

结论：通过。限制是增长率明细通常依赖第三方平台口径。

## 后续建议

1. 第一次实战使用时，建议按顺序测试一条完整链路：热门文章查询 → 标题生成 → 文案创作 → 封面图制作。
2. 每次发现某个入口输出变长，优先删 prompt 里的要求，而不是新增流程。
3. 对联网型入口，最好逐步沉淀固定数据来源账号或榜单截图，减少每次临时搜索的不确定性。
