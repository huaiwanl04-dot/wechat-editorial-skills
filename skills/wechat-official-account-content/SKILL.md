# 公众号创作技能包

这个 Skill 保留 7 个内容入口，并作为公众号工作流路由器。内容任务在这里完成；案例核验、审稿、编辑长图、Photoshop 交付和视觉质检交给职责更窄的专业 Skill，不在一个上下文里重复实现全部能力。

## 核心原则

1. 以用户给出的 7 个技能为主方向：标题生成、10w+文章、热门文章查询、封面图制作、文案创作、黑马账号推荐、热门账号推荐。
2. 默认先给“可直接执行版”，再给必要理由和下一步动作。
3. 简单任务直接完成；多案例、长图、PSD 或发布级交付按门禁分阶段执行。只加载当前阶段需要的最小 Skill 集合。
4. 能删冗余就删冗余：输出只保留会影响打开率、完读率、转发、品牌认知或业务转化的内容。
5. 涉及“最新、今天、最近、热点、趋势、榜单、10w+、增长率”时，必须先联网核实；无法联网时，基于用户给的材料继续完成分析，同时要求用户补充来源或把结论标为“待核实”。
6. 不编造阅读量、增长率、榜单排名、案例实效数据。没有数据时，把判断降级为“观察、推测或创作启发”。
7. 「未来弧线」相关内容必须把外部爆款和趋势转译回“美院背景创意工作室、巨型艺术装置、策展式商业、商业/文旅甲方、业务转化”的定位，不能写成泛公众号爆款或普通商业地产营销号。
8. 数据源分层使用：微信后台、自有项目数据、甲方确认数据可作为强证据；新榜、西瓜数据等第三方平台可作为趋势、选题、对标线索；自媒体文章、案例软文只作灵感和待核实素材。第三方平台数据不能单独证明真实阅读、真实粉丝、转化率或 ROI。

## 专业路由

| 任务 | 使用 Skill | 本 Skill 的职责 |
|---|---|---|
| 多案例检索、事实核验、配图、图片版权 | `wechat-case-research` | 提供选题与目标读者 |
| 事实、逻辑、夸大和发布风险 | `wechat-adversarial-review` | 提供原稿与品牌资料 |
| 完读、流失、反感和行动动机 | `wechat-reader-simulation` | 提供原稿与读者定位 |
| 合并反馈并形成定稿 | `wechat-final-editor` | 提供原稿和修改目标 |
| 连续公众号长图、杂志式视觉、缩略校样 | `wechat-editorial-longform` | 提供锁定文案与图片顺序 |
| 分层 PSD/PSB、字体、智能对象和切片 | `wechat-photoshop-delivery` | 不重复设计 |
| 手机阅读、重叠、裁切、切片和源文件验收 | `wechat-visual-qa` | 接收确认版作为基准 |

同一请求跨越多个阶段时，按 `references/content-operation-workflow.md` 执行门禁；不得在视觉未确认时提前批量生成源文件。

## 输入类型

可接受以下任意输入：

- 关键词、热点、行业新闻、选题想法。
- 标题、开头、大纲、完整草稿。
- 公众号文章链接、标题列表、爆文榜单、竞品账号名单。
- 微信后台导出数据、手工整理数据表、增长记录。
- 封面需求、参考封面、视觉方向、品牌资料。
- 「未来弧线」品牌内容、巨型装置案例、商业空间、文旅项目、艺术装置项目资料。

## 旧入口合并规则

| 用户说法 | 收拢到哪个主技能 |
|---|---|
| 选题规划、热点追踪、找灵感 | 公众号热门文章查询，必要时接 公众号文案创作 |
| 爆文参考、10w+、每日爆文 | 公众号10w+文章 |
| 标题优化、开头优化、打开率 | 公众号标题生成 |
| 写文章、改文章、品牌化改写、去 AI 味、AI 质检、发布前复盘 | 公众号文案创作 |
| 封面字、封面方向、封面设计 | 公众号封面图制作 |
| 对标账号、增长快的账号 | 公众号黑马账号推荐 |
| 头部账号、榜单、领域大号 | 公众号热门账号推荐 |
| 数据分析、发布后复盘 | 优先归入公众号文案创作；涉及账号/榜单对比时归入黑马或热门账号推荐 |

## 7 个主技能

### 1. 公众号标题生成

当用户输入关键词、选题、草稿、标题或要求“爆款标题、标题没想法、提升打开率”时使用。

执行要点：

1. 如用户要求结合爆款、热点或趋势，先联网查同类热门标题；无法联网时基于用户素材生成，并标明未核实外部趋势。
2. 读取 `references/title-and-opening.md`。
3. 如果是未来弧线内容，同时读取 `references/brand-future-arc.md` 和 `references/giant-installation-positioning.md`，标题要面向商业/文旅甲方，不要只追泛流量。
4. 输出 10-15 个标题，分为稳妥版、增长版、品牌版。
5. 每个标题只保留一句判断：吸引点或风险。
6. 同步给 3 个封面字建议和 1 个推荐标题。

默认输出：

```markdown
## 标题候选
| 类型 | 标题 | 吸引点 | 风险 |
|---|---|---|---|

## 推荐标题
[标题]：[一句理由]

## 封面字
1. 
2. 
3. 
```

### 2. 公众号10w+文章

当用户要求“推送10w+文章、找爆文参考、研究爆文特征、每日爆文”时使用。

执行要点：

1. 联网查找近期公开可验证的高传播公众号文章、行业爆文或第三方榜单；无法核实阅读量时，不写成真实 10w+，只标为“疑似高传播案例”。
2. 重点分析标题、选题、开头、结构、转发理由，而不是堆链接。
3. 输出“可借鉴”和“不能照搬”两列，避免把不相关爆文硬套到未来弧线。
4. 如果用于未来弧线，最后必须转译成巨型艺术装置/策展式商业可用角度。
5. 用户要求订阅每日推送时，先给“每日查看模板”和“固定检索口径”；不要假装已经建立自动订阅，除非实际创建了自动化。

默认输出：

```markdown
## 10w+ / 高传播文章参考
| 文章/标题 | 账号/来源 | 时间 | 爆点 | 可借鉴 | 不能照搬 |
|---|---|---|---|---|---|

## 提炼出的爆文特征
1. 
2. 
3. 

## 可转译为未来弧线的角度
1. 
2. 
3. 
```

### 3. 公众号热门文章查询

当用户输入关键词，要求“查热门文章、看当前什么内容在火、找同赛道灵感、竞品文章分析”时使用。

执行要点：

1. 围绕关键词主动搜索近期公众号/行业热门内容，必须标明来源和时间。
2. 读取 `references/topic-selection.md`；如果是未来弧线，再读取 `references/topic-project-system.md`。
3. 不只列文章，要判断哪些热点值得写、哪些只是热闹。
4. 对未来弧线选题做快速三问：是否强化巨型装置/策展式商业标签，是否体现专业壁垒，是否击中商业/文旅甲方痛点。
5. 输出“直接写、重切角度、只做素材、放弃”四类建议。

## 不建议追的方向

### 4. 公众号封面图制作

当用户要求“做封面图、封面设计、封面方向、封面字、2.35:1 横版封面”时使用。

执行要点：

1. 如用户要求参考同赛道爆款封面，先联网或基于用户给的参考图分析视觉元素。
2. 先确认封面模式：`原图`、`按 2.35:1 裁切原图`或`设计封面`。用户说“原图即可”时，不叠字、不加装饰、不替换图片，只交付对应高清原文件。
3. 设计封面时输出 2.35:1 横版方案，包含主题、主视觉、封面字、构图、色彩、字体气质、素材需求。
4. 对未来弧线，封面必须强化“巨型艺术装置/空间现场/策展式商业”视觉识别，避免普通营销海报感。
5. 如果用户要求直接生成或导出图片，必须实际生成文件并检查尺寸、裁切与可打开性；最终回复直接展示图片或提供可点击文件路径。只给方案、HTML 或口头说明不算完成。
6. 已有授权高清实拍且用户要忠实呈现时，优先使用确定性裁切/排版；只有确实需要新视觉内容时才使用图像生成。
7. 不用过多解释设计理念，重点给可执行规格。

### 5. 公众号文案创作

当用户要求“写公众号、生成文章、基于爆款写文、改写、去 AI 味、品牌化改写、AI 质检、发布前复盘、增长转化设计”时使用。这个入口承接大多数正文相关任务。

执行要点：

1. 如果用户只给关键词，先用一句话确认核心角度，然后直接输出标题、摘要、封面字和正文。
2. 默认生成“可直接发布版”，标准版控制在 1200-1800 字；除非用户明确要求深度长文。
3. 基于爆款数据时，只提炼标题、结构、钩子和转发理由，不照搬观点和表达。
4. 所有文章读取 `references/writing-workflow.md`、`references/personal-voice.md`、`references/content-density.md`。
5. 未来弧线文章必须读取 `references/brand-future-arc.md` 和 `references/giant-installation-positioning.md`。
6. 涉及行业案例、公共艺术、商业空间、文旅、商业地产时，按需读取 `references/professional-credibility.md`、`references/critical-insight.md`、`references/concept-boundaries.md`。
7. 如果用户给的是草稿，不要重新开一套流程，直接做：发布判断、主要问题、可直接替换版。
8. 结尾默认给互动问题、私域承接话术、小红书/视频号标题方向。
9. 外部案例多、事实字段多或图片版权不清时，先调用 `wechat-case-research`；未核实内容不能进入发布终稿。
10. 正文确认后，如用户要公众号长图或 PSD，先将终稿交给 `wechat-editorial-longform`，不要在文案阶段直接批量排版。

未来弧线文章主叙事顺序：

```text
空间问题 → 装置创作判断 → 尺度/材料/工艺/场地拆解 → 商业结果 → 低压力咨询承接
```

默认输出：

```markdown
## 可直接发布版

**标题：**
**封面字：**
**摘要：**

[正文]

## 文末互动
[问题]

## 私域承接
[低压力话术]

## 小红书 / 视频号方向
- 小红书标题：
- 视频号钩子：
```

草稿质检默认输出：

```markdown
## 发布判断
- 建议：
- 最大问题：
- 最该保留：

## 必改问题
| 问题 | 影响 | 改法 |
|---|---|---|

## 可直接替换版
[标题、开头、关键段落、结尾 CTA]
```

### 6. 公众号黑马账号推荐

当用户要求“黑马账号、阅读增长率排行榜、哪些号在猛涨、找增长对标”时使用。

执行要点：

1. 联网查近期增长快的公众号、第三方榜单或用户提供的数据；无法验证增长率时，不写具体排名。
2. 重点看增长动作：选题切口、标题风格、更新频率、账号定位、转发场景、内容形态变化。
3. 输出适合未来弧线借鉴的策略，不建议照搬的策略，以及下周可测试动作。
4. 不把泛娱乐、泛情绪爆号直接当未来弧线对标；除非只借鉴标题或分发机制。

### 7. 公众号热门账号推荐

当用户要求“热门账号、头部账号、综合实力榜、日榜/周榜/月榜、按分类查公众号”时使用。

执行要点：

1. 联网查榜单、公开账号数据或用户提供的名单，标明榜单口径和时间。
2. 区分热门账号和黑马账号：热门账号看长期影响力、内容资产和稳定打法；黑马账号看增长变化。

## 输出质量标准

- 输出要短、准、能复制使用。
- 不把旧流程完整展开，除非用户明确要求“完整流程”。
- 不堆方法论，不重复解释同一个判断。
- 标题不做虚假悬念，不承诺无法证明的效果。
- 文章不因短段落变成长文；标准版默认 1200-1800 字。
- 未来弧线内容必须先体现装置专业度，再谈商业结果。
- 对外部数据、阅读量、榜单、增长率和案例成效保持可核实。
- 文案完成不等于视觉完成；视觉校样、可编辑源文件和发布切片必须分别通过对应门禁。
