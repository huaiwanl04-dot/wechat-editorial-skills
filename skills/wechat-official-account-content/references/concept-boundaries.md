# 概念边界与专业术语

## 使用场景

当文章涉及公共艺术、商业美陈、艺术装置、策展式商业、展陈、赛事氛围、打卡点、IP 装置、空间设计时，必须使用本指南。

目标是避免概念泛化，尤其是把“摆个打卡点”误写成“公共艺术”。

## 核心原则

专业文章可以用通俗表达，但不能模糊基本边界。

如果一个案例主要服务商业促销、节庆氛围或赛事装饰，不要直接称为公共艺术。可以写成：

- 商业美陈。
- 赛事氛围装置。
- 品牌体验装置。
- 场景化展陈。
- 公共空间中的艺术化表达。

## 常见概念边界

| 概念 | 更准确的判断 | 容易误写 |
|---|---|---|
| 公共艺术 | 具有公共空间属性、公共参与、艺术表达或议题性 | 所有放在公共空间里的装置 |
| 商业美陈 | 服务商业氛围、节日节点、促销活动和视觉吸引 | 公共艺术 |
| 艺术装置 | 以材料、空间、感知和观念组织体验 | 普通道具、拍照背景 |
| 策展式商业 | 用策展逻辑组织空间、内容、动线和消费体验 | 单纯把空间做漂亮 |
| 打卡点 | 为拍照和传播设计的空间触点 | 自动等同于转化入口 |
| IP 装置 | 围绕品牌/IP 识别资产展开的空间表达 | 任何卡通造型 |
| 展陈 | 信息、物件、叙事和路径的展示组织 | 随意摆放物料 |

## 写作处理方式

如果概念不确定，使用更稳妥的表达：

- “更接近商业美陈，而不是严格意义上的公共艺术。”
- “它借用了公共艺术的空间方法，但目标仍然是商业传播。”
- “这个案例不能简单归为艺术装置，更像赛事节点下的场景化运营。”
- “这里讨论的不是艺术史意义上的公共艺术，而是商业空间如何借用公共艺术的组织方式。”

## 专业边界提醒

文章必须避免：

- 把所有视觉装置都叫公共艺术。
- 把所有可拍照场景都叫艺术装置。
- 把所有美陈都写成品牌资产。
- 把所有客流聚集都写成转化。
- 把公共性、艺术性、商业性混在一起不区分。
