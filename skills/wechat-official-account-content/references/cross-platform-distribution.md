# 小红书与视频号分发

## 使用场景

当用户完成公众号文章后，需要同步更新小红书、视频号、朋友圈或社群时，使用本指南。

跨平台分发不是把公众号文章复制过去，而是把同一个核心判断拆成不同平台能消费的入口。

## 分发原则

- 公众号：承载完整观点、品牌调性、转化链路。
- 小红书：强化场景、痛点、标题钩子、收藏价值和评论互动。
- 视频号：强化开头 3 秒、口播节奏、画面提示和转发理由。
- 朋友圈/社群：强化个人判断和低压力互动。

## 小红书分页规则（文案与成图共用）

不设默认固定页数或固定页数区间。“大约、左右、参考”等数量只是规划参考，不得转成强制数量或最小/最大值。公众号长图与小红书逐页图文采用不同交付形式，但保留同一账号的已确认视觉体系。

- 依据重要案例完整性、观点与证据对应、素材质量、单页信息密度和手机连续阅读节奏决定页数。
- 不为控制页数删除重要案例、必要证据或事实限定；不为凑页重复图片/观点、增加装饰空页或拆散完整观点。
- 同一作品可以展示不同视角，但各图应提供全景、工艺、细节或尺度等新增信息；重复出现须有叙事作用，不能用于填页。
- 内容过密先删重复表达或调整分页，不缩小正文、删掉事实成立条件来迁就模板。
- 只有用户明确的硬性数量要求，或经核实的平台限制，才形成约束；与完整性冲突时说明取舍并请求确认。
- 页码、总页数、导出清单和自动检查从本期确认的页面清单生成；禁止继承旧项目页数或测试区间。页数匹配不等于内容完整。

参数语义：`pageCountMode: content-driven`；`planningHint` 可为空或记录用户参考数量；`hardMin/hardMax` 默认空，仅在有明确依据时设置；`confirmedPageCount` 从锁定页面清单计算。字段可映射现有配置，不另建平行真源。不要把“约 N 页”转换为 `min=N-1,max=N+1`。

## 压缩与核验

跨平台重写后使用 `wechat-final-editor` 的语义复核，再制作页面。标题和封面不得采用比正文更强而无证据的说法。原文已核实不免除对压缩稿和实际成图的复核。

## 小红书输出

默认输出：

```markdown
## 小红书分发

### 标题备选
1. [痛点型]
2. [反常识型]
3. [场景型]
4. [收藏型]
5. [品牌观察型]

### 正文文案
[用更短、更有现场感的表达重写，不照搬公众号正文]

### 封面字
- [6-12 字，直给冲突或痛点]

### 话题标签
#商业空间 #空间设计 #艺术装置 #品牌空间 #未来弧线

### 评论区引导
[引导用户描述自己的空间问题]
```

写小红书时：

- 开头要更快，第一句就给痛点或反常识。
- 多用具体场景，少讲宏大品牌理念。
- 标题可以更直接，但不能标题党。
- 结尾适合问“你更缺进店理由、停留理由，还是传播理由？”

## 视频号输出

默认输出：

```markdown
## 视频号分发

### 视频标题
[一句话表达冲突或判断]

### 封面字
[6-10 字，能一眼看懂]

### 口播开头
[前 3 秒钩子]

### 口播脚本
[30-90 秒，短句，适合说出来]

### 画面建议
1. [镜头/画面]
2. [镜头/画面]
3. [镜头/画面]

### 结尾互动
[引导评论或私信]
```

写视频号时：

- 第一句必须抓住人，不要铺背景。
- 每 10-15 秒给一个画面或判断变化。
- 口播要像说话，不要像文章朗读。
- 结尾只给一个行动，不要同时求关注、点赞、转发、私信。

## 从公众号文章拆分

拆分顺序：

1. 找出公众号文章的核心判断。
2. 选一个最有冲突的读者痛点。
3. 小红书写成“场景 + 判断 + 建议”。
4. 视频号写成“钩子 + 解释 + 例子 + 一个问题”。
5. 所有平台都保留未来弧线的品牌判断，但不硬塞品牌介绍。
