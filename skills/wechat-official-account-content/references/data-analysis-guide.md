# 公众号数据分析指南

## 支持的数据

可分析：

- 微信公众平台后台导出的 CSV 或 XLSX。
- 用户手工整理的文章数据表。
- 竞品文章标题、发布时间和公开阅读表现。

## 推荐字段

| 字段 | 说明 |
|---|---|
| 标题 | 必备，分析标题模式和主题 |
| 发布时间 | 推荐，用于分析星期和小时表现 |
| 阅读量 | 推荐，基础表现指标 |
| 分享 | 推荐，判断传播能力 |
| 收藏 | 推荐，判断实用价值 |
| 点赞/在看 | 可选，判断认可度 |
| 评论/留言 | 可选，判断互动 |
| 打开率 | 可选，判断标题和封面 |
| 点击率 | 可选，判断外链或转化 |
| 完读率 | 可选，判断内容结构 |

## 脚本用法

```powershell
python scripts/analyze_wechat_data.py path\to\data.csv
python scripts/analyze_wechat_data.py path\to\data.xlsx --sheet Sheet1 --output report.md
```

如果当前环境没有 `python` 命令，使用 Codex 可用的 Python 运行时执行脚本。

## 解读原则

- 阅读量高：说明选题、标题、分发至少有一个环节有效。
- 分享高：说明文章具备社交表达价值。
- 收藏高：说明文章具备工具价值或长期参考价值。
- 打开率低：优先优化标题、封面、账号信任和发布时间。
- 完读率低：优先优化开头、结构、篇幅和信息密度。
- 点击率低：优先检查行动引导、链接位置和读者动机。

## 输出要求

数据分析后不要只给数字，必须转成内容动作：

- 下次优先写什么主题。
- 哪类标题应该继续使用。
- 哪类选题需要减少。
- 发布时间有什么倾向。
- 哪篇文章值得二次改写或做系列。
- 哪些内容适合改成小红书标题/正文。
- 哪些内容适合改成视频号标题/口播钩子。

## 跨平台输出

```markdown

### 小红书
| 来源文章 | 标题方向 | 正文切入 | 封面字 | 评论引导 |
|---|---|---|---|---|

### 视频号
| 来源文章 | 视频标题 | 前 3 秒钩子 | 口播角度 | 结尾互动 |
|---|---|---|---|---|
```
