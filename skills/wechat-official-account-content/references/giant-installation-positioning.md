# 巨型艺术装置定位

## 使用场景

当文章涉及「未来弧线」、巨型艺术装置、艺术装置、策展式商业、商业空间、公共艺术、文旅场景或品牌空间时，必须使用本指南。

目标是防止内容滑向普通商业地产营销号。未来弧线的核心识别不是“会做流量转化”，而是“以艺术家创作能力和巨型装置落地能力，重塑商业空间的体验和记忆”。

## 主叙事优先级

未来弧线文章的叙事顺序必须是：

1. 空间问题：这个场地为什么需要被重新组织。
2. 装置判断：为什么需要巨型装置/大尺度艺术介入。
3. 创作拆解：尺度、材料、结构、工艺、光影、视线、动线、观看路径。
4. 场景体验：人如何靠近、停留、仰视、穿行、拍摄、记住。
5. 商业结果：传播、客流、转化、品牌资产。

商业转化是结果，不是主叙事。不能让“流量、转化、动线”压过“装置本身如何成立”。

## 巨型装置案例分级

写未来弧线文章时，案例必须先分级。

| 等级 | 类型 | 能否作为主案例 |
|---|---|---|
| A | 巨型艺术装置 / 大尺度空间介入 / 建筑尺度装置 | 可以作为主案例 |
| B | 中大型艺术装置 / 明确空间叙事 / 可改变观看路径 | 可以作为辅助主案例 |
| C | 商业美陈 / 赛事氛围 / 中小型展陈 / 手绘或轻量布置 | 只能作为辅助或边界说明 |
| D | 普通物料 / 展板 / 轻量打卡背景 / 店内小装饰 | 不适合作为未来弧线主文章案例 |

硬规则：

- 主案例至少 70% 必须是 A/B 类。
- C/D 类不能承担核心论证。
- 如果素材里只有 C/D 类案例，文章应改成“边界提醒/反例分析”，不要包装成巨型装置方法论。

## 装置专业拆解维度

每篇未来弧线专业文章至少拆解 3 个维度：

- 尺度：装置与人、建筑、街区、入口、中庭、天花、立面的比例关系。
- 材料：材料为什么适合这个空间，如何影响质感、耐候、安全和维护。
- 结构：如何支撑、吊装、固定、拆装、运输、抗风或承重。
- 工艺：制作方式、表面处理、灯光控制、模块化、现场安装难点。
- 光影：白天/夜晚、自然光/人工光、反射、投影、可见距离。
- 观看路径：远看、近看、穿行、停留、拍摄时分别看到什么。
- 场地关系：装置如何回应建筑、商业动线、人流入口和周边业态。
- 策展叙事：装置和品牌、城市、节日、项目主题之间如何建立意义。

如果文章没有这些拆解，只谈“引流、打卡、转化”，就不符合未来弧线的专业定位。

## 艺术家视角

未来弧线内容要体现美院艺术家团队优势。写作时优先补充：

- 艺术家为什么选择这个形态。
- 这个尺度为什么成立，不是随便放大。
- 这个材料和工艺如何服务表达。
- 艺术表达和商业诉求在哪里冲突，又如何平衡。
- 装置落地中最难的部分是什么。
- 如果只追求拍照，哪里会牺牲艺术和空间体验。

## 禁止偏移

避免把未来弧线文章写成：

- 商业地产运营号：只讲流量、动线、转化、客流。
- 普通美陈公司：只讲节日氛围、出片、打卡。
- 装修设计公司：只讲风格、高级感、空间颜值。
- 公关传播号：只讲曝光、社媒声量、话题。

这些都可以作为结果或辅助判断，但不能成为文章主轴。

## 写作前检查

写未来弧线文章前，先回答：

1. 这篇文章如何强化“巨型艺术装置”标签？
2. 主案例是否真的是 A/B 类大尺度装置？
3. 是否拆解了尺度、材料、工艺、结构或场地关系？
4. 是否体现艺术家创作判断？
5. 商业转化是否只是结果，而不是抢走主叙事？
6. 有没有把轻量美陈、赛事氛围或展板当成主案例？
