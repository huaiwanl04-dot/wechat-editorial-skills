# 阅读增长与复盘手册

## 增长拆解

公众号阅读增长通常来自：

- 打开率：标题、封面、账号信任、发布时间。
- 完读率：开头、结构、信息密度、排版节奏。
- 转发率：身份表达、实用价值、观点共鸣、社交谈资。
- 关注率：账号定位清晰、连续内容承诺、结尾引导。
- 转化率：读者信任、行动门槛、产品或服务匹配度。

## 发布前检查

| 模块 | 检查问题 |
|---|---|
| 标题 | 是否清楚说明读者收益或冲突？ |
| 封面 | 是否能在列表里一眼看懂主题？ |
| 开头 | 前 150 字是否进入正题？ |
| 结构 | 小标题是否能独立表达逻辑？ |
| 证据 | 事实、数据、案例是否可信？ |
| 转发点 | 读者转发时是在表达什么身份或观点？ |
| 结尾 | 是否有清晰互动或关注理由？ |

## 低成本增长动作

1. 每篇文章至少准备 3 个标题方向，再选主标题。
2. 建立固定栏目，让读者形成预期。
3. 把长文拆出 3 到 5 条朋友圈或社群转发话术。
4. 同步拆出小红书标题/正文和视频号标题/口播钩子，不照搬公众号全文。
5. 发布后 2 小时内观察打开和转发，必要时调整分发话术。
6. 每周复盘高表现文章的标题、选题、发布时间和转发理由。

## 7 天行动表

```markdown
| 天数 | 动作 | 产出 | 观察指标 |
|---|---|---|---|
| D1 | 整理历史文章数据 | 高低表现文章清单 | 阅读、分享、收藏 |
| D2 | 选出 3 个高潜主题 | 选题表 | 相关度、可写性 |
| D3 | 打磨标题和开头 | 标题组、开头 3 版 | 打开率预估 |
| D4 | 完成文章初稿 | 初稿 | 结构完整度 |
| D5 | 优化转发点 | 分发话术 | 转发理由 |
| D6 | 发布并记录数据 | 发布记录 | 2 小时、24 小时数据 |
| D7 | 复盘 | 下周优化动作 | 高低表现差异 |
```

## 复盘问题

- 哪类选题带来更高阅读？
- 哪类标题打开更好？
- 哪个发布时间更稳定？
- 高分享文章有什么共同情绪或价值？
- 收藏高但分享低，是否说明内容实用但传播钩子弱？
- 阅读高但关注低，是否说明账号定位或结尾承接不足？
