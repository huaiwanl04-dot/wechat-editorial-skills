# 未来弧线选题立项系统

## 使用场景

当用户要求选题规划、热点追踪、月度内容计划、文章立项、案例筛选、栏目规划时，必须使用本系统。

目标是从源头避免：

- 选题跑偏：写成普通商业地产、运营、营销号内容。
- 定位模糊：弱化“巨型艺术装置 + 策展式商业”标签。
- 业务脱节：文章有阅读，但不能触达商业/文旅甲方的决策需求。

核心逻辑：

```text
先锚定自身标尺
再筛选外部素材
再做差异化切割
最后形成业务闭环
```

## 立项前：三维适配标尺

所有选题先过三维适配。满足 2 项以上才值得推进；如果“标签适配”完全不通过，必须重切角度或放弃。

### 1. 标签适配

判断：能不能强化核心人设？

必须紧扣至少一个核心标签：

- 巨型艺术装置。
- 策展式商业。

正向标准：

- 能体现大尺度装置的创作、设计、落地。
- 能体现用策展思维组织商业空间、公共艺术或品牌体验。

反向排除：

- 纯营销玩法。
- 小型美陈摆件。
- 普通空间运营技巧。
- 只有流量、打卡、折扣、活动，没有装置专业度。

### 2. 专业适配

判断：能不能发挥美院艺术家团队优势？

正向切入：

- 尺度设计。
- 材料工艺。
- 场地适配。
- 艺术表达。
- 策展逻辑。
- 结构落地难点。

反向避雷：

- 纯流量数据分析。
- 纯运营技巧。
- 纯营销套路。
- 谁都能写的商业空间水文。

### 3. 受众适配

判断：能不能击中商业/文旅甲方的真实需求？

核心读者：

- 商业地产操盘手。
- 文旅项目负责人。
- 品牌空间主理人。
- 商场、园区、酒店、展厅、商业街区负责人。

典型痛点：

- 预算有限，如何做有识别度的地标装置。
- 存量空间如何艺术化激活。
- 节庆/赛事装置如何兼顾短期热度与长期资产。
- 如何让装置带动停留、传播、咨询或项目认知。
- 如何判断一个空间适不适合做巨型装置。

## 素材筛选期：三层切割

确定方向后，不要直接写稿。先切掉不符合定位的素材。

### 1. 尺度切割

优先保留：

- 单装置主体高度约 3 米以上。
- 具备空间地标属性。
- 对人流视线、空间关系或场地体验有明显影响。
- 属于公共空间中的艺术装置、策展式空间或大尺度场景介入。

直接降级或砍掉：

- 手绘、展板、普通物料。
- 小型陈列。
- 文创周边。
- 只有氛围、没有空间介入的轻量布置。

### 2. 视角切割

同样案例，避开营销号视角，使用艺术家/策展人视角。

| 普通营销号视角 | 未来弧线视角 |
|---|---|
| 这个装置带了多少客流 | 这个装置的尺度如何匹配场地的人流视线 |
| 这个装置打卡率很高 | 这个装置如何组织观看路径和停留动作 |
| 这个装置传播效果好 | 这个装置如何平衡艺术表达与商业需求 |
| 这个活动很热闹 | 这个空间为什么需要大尺度装置介入 |

### 3. 价值切割

落点必须从短期营销转向长期资产。

优先写：

- 装置如何成为空间记忆点。
- 装置如何沉淀为品牌资产。
- 装置如何让普通建筑具备可持续传播的空间 IP。
- 节点活动结束后，空间还能留下什么。

避免只写：

- 蹭热点。
- 搞活动。
- 冲流量。
- 一次性打卡。

## 选题类型与栏目归档

每个选题必须归入一个栏目。归不了类，通常说明定位不清。

| 栏目 | 作用 | 适合选题 |
|---|---|---|
| 全球巨型装置案例库 | 建立专业案例资产 | 城市/赛事/文旅/商业空间巨型装置拆解 |
| 策展式商业笔记 | 输出行业判断 | 存量空间激活、装置长尾价值、空间叙事 |
| 工作室创作手记 | 强化真实感与专业壁垒 | 自有项目幕后、材料工艺、落地过程 |
| 甲方决策指南 | 服务业务转化 | 什么空间适合做巨型装置、预算如何判断 |
| 边界与避坑 | 建立信任 | 什么时候不该做打卡装置、公共艺术误区 |

## 巨型装置案例类固定骨架

适用于全球案例、城市案例、赛事案例、文旅案例、商业空间案例。

### 1. 开篇痛点引入：10%

从甲方真实痛点进入。

不要从“某热点来了”泛泛开头，而是从问题开头：

- 花了钱做装置，为什么拍完照就没人记得？
- 商业空间为什么有活动，却没有空间资产？
- 巨型装置为什么不是把东西做大就行？

### 2. 核心案例拆解：70%

选 3-4 个核心案例，每个案例按四维拆解：

1. 基础信息：体量、位置、创作方、落地背景。
2. 尺度与场地适配：大小、视线、人流、动线、空间关系。
3. 创作与工艺亮点：艺术表达、材料、工艺、结构、落地难点。
4. 策展与商业价值：传播、客流、停留、品牌记忆、空间资产。

### 3. 方法论提炼：15%

提炼 2-3 个可复用判断：

- 巨型装置不只是大，而是要改变观看关系。
- 节点装置要考虑活动结束后的长尾价值。
- 策展式商业的重点不是热闹，而是把场地变成可记忆资产。

### 4. 转化引导：5%

自然引导业务：

- 如果你正在筹备商业/文旅项目的巨型艺术装置，可以先从场地尺度、客流路径和长期传播目标判断。
- 如果你有空间照片、项目定位或节点活动计划，可以发来一起判断它适合做地标装置、策展式装置，还是轻量场景更新。

## 上线前：甲方视角验证

初稿完成后，站在目标甲方角度检查。

有一项不通过，就回到选题或骨架调整。

| 验证项 | 问题 |
|---|---|
| 专业感 | 看完是否觉得这个团队懂装置、懂创作、懂落地？ |
| 收获感 | 看完是否学到可复用思路，或刷新对巨型装置的认知？ |
| 转化感 | 如果我有装置设计需求，会不会想到找这个团队合作？ |

## 上线后：选题复盘沉淀

不要只看阅读量。每篇文章发布后记录三类数据：

| 类型 | 指标 | 用途 |
|---|---|---|
| 传播数据 | 阅读、在看、转发、收藏 | 判断受众广度 |
| 业务数据 | 私信咨询、新增好友、客户提及、项目线索 | 判断精准度和转化价值 |
| 反馈数据 | 留言、客户问题、被反复追问的点 | 反推下一篇选题 |

复盘后必须归档：

- 这个选题属于哪个栏目。
- 是否强化巨型装置标签。
- 是否带来业务线索。
- 下次应该继续、改角度，还是停止。
