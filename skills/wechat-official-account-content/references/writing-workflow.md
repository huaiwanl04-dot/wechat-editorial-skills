# 公众号文章写作流程

## 文章前置判断

写正文前先确定：

- 目标读者：谁会点开，谁会读完，谁会转发。
- 核心承诺：读者读完能获得什么。
- 文章类型：解释、观点、教程、清单、案例、复盘、种草、品牌内容。
- 发布目标：阅读、转发、关注、咨询、成交、建立专业感。
- 篇幅模式：快速版、标准版、深度版。用户未指定时默认标准版。
- 证据等级：哪些案例有数据，哪些只是定性观察。
- 新判断：这篇文章不是行业共识的部分是什么。
- 适用边界：哪些场景不能照搬。
- 装置定位：这篇文章如何强化巨型艺术装置标签，而不是泛商业运营。

## 默认结构

```markdown
# 标题

开头：用事实、痛点、冲突或具体场景抓住注意力。

## 1. 先把问题说清楚
说明读者为什么要关心。

## 2. 给出核心判断
用清晰观点承接标题承诺。

## 3. 展开证据或方法
用案例、数据、步骤、对比支撑观点。

## 4. 给读者可执行动作
提供清单、建议、判断标准或下一步。

结尾：总结观点，给互动引导或行动建议。
```

## 未来弧线文章结构

涉及未来弧线、巨型艺术装置、策展式商业、商业空间案例时，优先使用这个结构，而不是普通商业运营文章结构：

```markdown
# 标题

开头：从空间问题或装置观察进入，不要只从流量/转化进入。

## 1. 这个空间真正缺的是什么
说明场地问题：尺度、动线、记忆点、观看关系或场景体验。

## 2. 为什么需要巨型装置介入
说明普通美陈、轻量物料或单纯运营动作为什么不够。

## 3. 装置本身如何成立
拆解尺度、材料、结构、工艺、光影、观看路径或场地关系。

## 4. 它如何转化为空间价值
再谈停留、拍照、传播、客流、咨询、品牌资产等商业结果。

结尾：引导读者判断自己的空间是缺装置记忆点、场地叙事，还是落地承接。
```

商业转化不能抢走主叙事。文章必须先让读者看到装置专业度，再看到商业价值。

## 写作原则

- 每段尽量只表达一个意思。
- 小标题要能串起来看懂全文。
- 开头 150 字要兑现标题，不绕远。
- 标准版默认控制在 1200-1800 字，不要因为短段落而把全文写长。
- 每 500 到 700 字安排一次节奏变化：例子、列表、提问、判断。
- 一个核心判断只证明一次，避免多个小节反复说同一件事。
- 行业案例必须区分“可验证数据、公开事实、一手观察、类比素材、个人判断”。
- 专业概念要稳妥使用，不把商业美陈、赛事氛围、打卡点都泛化成公共艺术。
- 未来弧线文章必须拆解至少 3 个装置专业维度：尺度、材料、结构、工艺、光影、观看路径、场地关系、策展叙事。
- 轻量美陈、展板、手绘、赛事氛围布置不能作为未来弧线主案例，只能作为边界或反例。
- 不为了情绪牺牲事实准确性。
- 品牌内容要先解决读者问题，再自然引出品牌价值。

## 常见文章模板

### 热点解释型

1. 发生了什么。
2. 为什么突然被关注。
3. 和读者有什么关系。
4. 该怎么看或怎么做。
5. 哪些信息还需要继续观察。

### 干货教程型

1. 痛点场景。
2. 判断标准。
3. 操作步骤。
4. 常见错误。
5. 可复制清单。

### 观点评论型

1. 引出争议或现象。
2. 给出明确观点。
3. 拆解反常识原因。
4. 用案例或数据支撑。
5. 回到读者处境。

### 案例复盘型

1. 案例背景。
2. 关键动作。
3. 结果变化。
4. 可复制经验。
5. 不可复制边界。
