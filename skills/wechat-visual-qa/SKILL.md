# 公众号视觉与交付质检

用证据阻止“文件生成成功但成品不可用”。按用户实际要求的交付范围检查；仅所需结构、内容、视觉、导出及源文件项目通过后，才能声明对应交付完成。未要求 PSD 时不强行添加 PSD 检查。

## 工作边界

- 不重新设计、不擅自改稿；发现问题时给出精确位置、影响和最小修复动作。
- 文案事实与逻辑风险交给 `wechat-adversarial-review`；本 Skill 检查视觉呈现和交付完整性。
- 不能用文件存在、脚本无报错或 Photoshop 成功保存代替视觉检查。

## 检查顺序

1. 读取 `references/qa-checklist.md`、锁定终稿、内容覆盖清单和项目约束，确认预期要点、案例、图片、章节、文案版本和文件清单。
2. 内容覆盖检查：逐项比对原稿/终稿要点与成图落点；“压缩”必须有合并记录，不能用视觉模块数代替内容完整性。
3. 结构检查：缺图、重复、错序、图层命名、智能对象、蒙版、字体状态。
4. 视觉检查：文字重叠/越界、图片主体、留白、层级、颜色、线条和装饰关系。
5. 手机检查：按目标显示宽度检查标题一秒可读、正文舒适度、注释可辨识度，并横向比较所有正文模块的实际字号与行距。
6. 字体检查：读取浏览器计算字体或 Photoshop 字体状态，确认指定字体及字重真实生效，不接受仅检查 CSS/图层名称。
7. 发布洁净检查：确认已删除板块、内部核验词、文件名、证据等级、资料说明和图片说明不会被模板带回。
8. 切片检查：逐条边界和完整拼接，确认无缝且不截断语义。
9. 一致性检查：PSD/PSB 渲染与确认版 PNG 对比。
10. 可见性检查：不能只统计图层存在；必须确认文字、智能对象和装饰处于正确层级，没有被大色块、错误蒙版、隐藏父组或裁切组遮挡。
11. 聚合门禁：代表页、单个切片或图层结构的 `PASS` 不能覆盖整篇交付报告的 `FAIL`。完整母版与全部切片必须重新做一致性检查。
12. 交付物检查：用户要求的封面、原图、摘要、HTML、母版或切片必须实际存在并可打开；描述了方案不等于已输出文件。
13. 输出阻断项；全部修复并复检后才给 `PASS`。

## 成图复核与分项结论（公众号 / 小红书）

- 打开实际导出图片，对照锁定文案、事实台账和页面清单逐页检查；重要改写依 `wechat-final-editor` 语义门禁复核，图文事实风险交 `wechat-adversarial-review`。不要用关键词命中代替语义判断。
- 小红书页数与文件数量从本期确认的页面清单获得，不硬编码固定页数/区间。页数正确不证明重要案例与观点完整；按 `../wechat-official-account-content/references/cross-platform-distribution.md` 检查无凑页、漏项与破坏性拆分。
- 修改后检查换行、孤字、数字与单位分离、文字重叠及手机阅读；指定字体既检查实际字体文件加载，又检查计算字体/字重，不接受 CSS 名称作为唯一证据。
- 记录内容核验、语义复核、视觉检查、导出一致性、用户确认、发布条件各自的状态与证据/版本；未执行记 NOT_RUN，不适用记 N/A 并说明。单项 PASS 不汇总成全流程 PASS。
- 文件生成、尺寸正确、字体加载或自评高分仅证明相应项目，不保证事实无误；未实际执行多 Agent 审核不得声称已完成。
- 修改后重新检查受影响页面与跨页关联；整套交付须验证各文件来自同一锁定版本，不混入旧图。保留旧版，提供新版真实文件及可点击入口。
- 已有用户确认先查对象、版本与范围。依据明确且范围未变则同步失效台账字段；不得凭视觉通过推断许可，也不得因旧记录反复要求同一确认。

## 工具原则

- 浏览器全页截图可用 Playwright 类工具复现稳定渲染。
- 像素差异可用 pixelmatch 类工具辅助，但不能代替主体裁切和阅读体验判断。
- 图片尺寸、拼接和联系表可用 Sharp 类工具处理；自动 attention/entropy 裁切必须人工复核。
- 不为一次检查安装未经审计的插件；先评估许可证、维护状态、安全风险和适配成本。
- 已有 JSON QA 报告时，优先运行 `scripts/audit-wechat-delivery.js` 做确定性聚合检查，再进行人工视觉复核。

## 完成定义

阻断项按范围报告：已导出的文件可如实交付，但内容/授权未清不能宣称可发布，PSD 未验证不能宣称完全可编辑。不得用视觉 PASS 覆盖内容或发布 FAIL。以下问题使对应检查项为 `FAIL`，需要该项的完整发布交付亦不通过：

- 完整交付 QA 的聚合状态不是 `PASS`；
- Photoshop 渲染与用户确认版的像素差异超过项目阈值；
- 图层虽然存在，但可见成图出现大面积缺图、黑块、错误遮挡或隐藏内容；
- 无缝切片能重组，但重组后的内容与确认版不一致；
- 图片发布许可仍处于 `verify-before-publish`、未知或待确认状态。
- 指定字体未实际加载，或正文模块出现明显不一致字号而无设计理由；
- 用户要求的独立交付物（尤其封面或原图）没有真实文件，只提供了文字说明或预览方案；
- 发布成图仍含用户已要求删除的资料说明、图片说明或内部核验标记。
