# 公众号视觉 QA 清单

## 内容完整性

- 标题、摘要、章节、案例、图片、结尾模块与确认版一致。
- 原稿/终稿的每个已确认要点在成图中有明确落点；合并、压缩或删除都有记录，不能仅按章节编号抽查。
- 没有旧文案、占位字、缺图图标、重复图片或错误文件名。
- 已确认删除的板块没有被模板重新加入。
- 人物/工作室主导文章包含身份图、简介与项目证据；建筑尺度文章包含完整现场与细节证据。

## 实际成图的语义与分页

- 实际导出图已与锁定稿逐页比对，数字对应的作品、版本、测量对象、材料与合作限定清晰可见。
- 小红书的页数、页码、导出清单来自本期确认的页面清单，而非历史固定页数/区间。
- 没有为控制页数删除重要案例或为凑页重复图片、拆散完整观点；不同视角提供新增证据。
- 改稿后同步源文字、页面清单、核验记录并重新渲染受影响页面，整套不混入旧图。
- 内容/语义/视觉/导出/用户确认/发布条件分项有依据；主 Agent 自检与多 Agent 审核如实区分。

## 视觉

- 文字不重叠、不被图片遮挡、不越出安全区。
- 图片主体、动作、场地关系完整；没有无意义裁切。
- 主、中、快三类案例层级可见，不是案例目录式平均铺陈。
- 连续三组不重复同一图片结构。
- 线条、圆点和色面有明确的连接、分区、对齐或标注职责。

## 手机阅读

- 在目标缩略宽度下标题可迅速辨识。
- 正文不依赖放大阅读，Regular 字重优先。
- 浅色、细字、小字号不能同时出现。
- 图片说明可以小，但不能承担核心判断。
- 横向比较所有正文段落的计算字号、行距、字重和每行字数；简介区不能因双栏过窄或字号突降而形成明显阅读断层。

- 改字后没有孤字、异常换行或数字与单位分离；缩略总览不能代替手机正文可读性检查。

## 项目约束与洁净交付

- 指定字体及字重真实加载，无静默回退。
- 账号级字体基线与当前确认一致；当期配色能说明与人物、品牌、材料、场地或图片的关系，不机械继承上一期颜色，也不把某一期不用的颜色误判为永久禁色。
- 禁用组件、资料来源、图片说明和封面模式与当前确认记录一致，不继承上一期模板偏好。
- 面向读者的成图不含 `verify-before-publish`、`FACT`、内部文件名、版权待确认、测试水印或 QA 文案。
- 封面/原图/摘要等独立交付物真实存在、尺寸正确、可打开，并在最终回复中直接展示或给出可点击路径。

## Photoshop

- 文字图层可编辑；字体无静默替换。
- 图片是独立智能对象，可移动、缩放和替换。
- 蒙版独立且非破坏性。
- 分组和命名可理解；没有无意义副本。

## 切片与一致性

- 切片宽度一致，边界没有白缝、重复行或缺失行。
- 边界不切过文字、主体或连续装饰。
- 切片按顺序拼接后与完整长图一致。
- PSD/PSB 渲染与确认版 PNG 在允许的抗锯齿差异外一致。
